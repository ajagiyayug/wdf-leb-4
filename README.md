Practical 4: JavaScript DOM Manipulation, Event Handling, and UI Interactivity

Overview

This practical covers how to create dynamic UI components—such as collapsible FAQs, modal popups, image/content sliders, notification banners, hamburger navigation menus, and light/dark theme switchers—using vanilla JavaScript.

Purpose & Core Objectives

The primary purpose of this practical is to learn how to enhance user experience and client-side interactivity using modern JavaScript techniques.

Key Focus Areas:

DOM Selection & Manipulation: Accessing and updating HTML elements dynamically.

Event Handling: Attaching and managing interactive event listeners correctly.

State Persistence: Utilizing localStorage to save user preferences (like light/dark theme) across page reloads.

Usability & Accessibility: Creating smooth UI interactions while ensuring web accessibility standards (ARIA, keyboard navigation, contrast) are maintained.

Technical Details

Tools & Technologies: JavaScript (ES6+), HTML5, CSS3, Browser Developer Tools

Course Outcome Mapping: CO3, CO4

Target Applications: Interactive Web Dashboards & Dynamic Frontend Interfaces

Learning Outcome: Gain hands-on experience in selecting DOM nodes, handling UI events, manipulating CSS classes, using web storage APIs, and implementing basic animations.
